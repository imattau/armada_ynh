# Armada package for YunoHost

This repository packages the static Armada web client for YunoHost.

The first package iteration intentionally excludes the optional Nostr relay
and LiveKit voice backend. See the upstream project for those components and
their operational requirements:

<https://github.com/soapbox-pub/armada>

## Development status

Initial packaging scaffold. Test installation, sub-path routing, upgrades,
backups/restores, and the build on all supported YunoHost architectures before
publishing to the app catalog.
